Log Files Location

Full logs are stored in the following files on the Raspberry Pi:

  • logs/birdfm.log - Main application logs
  • logs/birdfm-error.log - Error logs
  • logs/webserver.log - Web interface logs

You can also view system service logs via SSH with: journalctl -u birdfm.service -f
